# Theatres

> Interactive 3D exploration of theatre spaces, developed at the intersection of software, spatial visualization and theatre research.

Theatres is an ongoing project exploring how digital 3D environments can be used to represent, inspect and think about theatrical space.

The project connects a background in **theatre direction and artistic research** with software development and interactive visualization.

## Concept

Theatre is not only a performance that happens on a stage. It is also a spatial system: bodies, architecture, scenic elements, audience, light and movement establish relationships that can be observed and represented.

This project experiments with representing those relationships through an interactive digital environment.

## Technical direction

The project explores:

- 3D scene construction and visualization.
- Interactive spatial interfaces.
- Theatre architecture and stage configurations.
- Digital representation of scenic space.
- JavaScript-based creative technology.
- Interaction between research/creative practice and software.

## Why this project matters

Theatres is part of a broader exploration of **creative technology**: using software not only as an engineering tool, but also as a medium for research, visualization and artistic practice.

It is intentionally developed as an evolving research/technology project rather than a finished commercial product.
